เกมบันไดงูตอบคำถาม

เกมทบทวนบทเรียนแบบกระดานบนจอหน้าห้อง เล่นเป็นทีม ใส่คำถามเองได้ทุกวิชา

คู่มือการใช้งาน • เวอร์ชัน 1.0 • System ห้องสื่อครูคอม

สารบัญ

  1. ระบบนี้ทำอะไรได้บ้าง
  2. การติดตั้งและเปิดใช้งาน
  3. เริ่มต้นครั้งแรก (ข้อมูลตัวอย่าง / ตั้งค่าโรงเรียน)
  4. ชุดคำถาม: สร้าง แก้ไข ใส่รูป นำเข้าจาก Excel
  5. ออกแบบกระดานบันไดงู (30–100 ช่อง)
  6. เล่นเกมหน้าชั้นเรียน
  7. ผลการแข่งขัน ประวัติคำถาม และรายงาน .docx
  8. พิมพ์กระดานและการ์ดคำถามเล่นแบบกระดาษ
  9. สำรองข้อมูลและย้ายเครื่อง
  10. คำถามพบบ่อย

1. ระบบนี้ทำอะไรได้บ้าง

  • ชุดคำถาม 3 ประเภท — ปรนัย 4 ตัวเลือก / ถูก-ผิด / เติมคำ (เฉลยได้หลายแบบ) ใส่รูปประกอบได้ทุกข้อ มีชุดตัวอย่าง 6 วิชา 72 ข้อ นำเข้าจาก Excel ได้
  • กระดานบันไดงู 30–100 ช่อง — ระบบวางบันได งู ช่องคำถาม และช่องพิเศษอัตโนมัติ หรือออกแบบเองทีละช่อง เก็บไว้ใช้ซ้ำได้หลายแบบ
  • เล่น 2–6 ทีม — ทอยลูกเต๋าแบบเคลื่อนไหว หมากเดินทีละช่อง ตกช่องคำถามต้องตอบภายในเวลา ตอบถูกเดินต่อ ตอบผิดถอย
  • ช่องพิเศษ — โบนัส (เดินหน้าเพิ่ม) หยุดพัก (ข้าม 1 ตา) ทอยอีกครั้ง
  • เต็มจอ เสียง แอนิเมชัน — ขึ้นบันได ไถลลงงู จับเวลาถอยหลัง ประกาศผู้ชนะพร้อมพลุและแท่นรางวัล
  • ประวัติคำถาม — ทีมไหนตอบข้อใด ตอบอะไร ถูกหรือผิด ใช้เวลากี่วินาที
  • เอกสาร — ใบสรุปผล (พิมพ์) และรายงานราชการ .docx: สรุปผลการแข่งขัน / บันทึกข้อความรายงานผลกิจกรรม / ชุดคำถามพร้อมเฉลย
  • เล่นแบบกระดาษ — พิมพ์กระดาน A4 แนวนอน + การ์ดคำถามหน้าละ 8 ใบ (เฉลยกลับหัว) + ใบเฉลยครู
  • ออฟไลน์ 100% — ไม่ต้องติดตั้ง ไม่ต้องต่ออินเทอร์เน็ต ข้อมูลอยู่ในเครื่อง สำรองเป็นไฟล์ .json

2. การติดตั้งและเปิดใช้งาน

  1. ดาวน์โหลดไฟล์ vs-snake-ladder-quiz-v1.0.zip แล้วแตกไฟล์ (คลิกขวา → Extract All / แตกไฟล์ทั้งหมด) — อย่าเปิดจากในไฟล์ zip โดยตรง
  2. เปิดโฟลเดอร์ที่แตกได้ ดับเบิลคลิก index.html ระบบจะเปิดใน Google Chrome หรือ Microsoft Edge
  3. ถ้าเปิดด้วยเบราว์เซอร์อื่น ให้คลิกขวาที่ index.html → Open with → Google Chrome
  4. ทุกครั้งที่ใช้ ให้เปิดไฟล์เดิมจากโฟลเดอร์เดิม ข้อมูลจะยังอยู่ (เก็บในเบราว์เซอร์ของเครื่องนั้น)
ต่อโปรเจกเตอร์/ทีวี: เปิดระบบบนคอมครู กดปุ่ม (หรือแป้น F) ให้กระดานเต็มจอ ใช้รีโมตพรีเซนต์ที่ส่งแป้น Space/Enter ทอยเต๋าได้
สิ่งที่ต้องมี: Google Chrome หรือ Microsoft Edge รุ่นปัจจุบัน • สำหรับเปิดไฟล์รายงาน .docx ใช้ Microsoft Word และฟอนต์ TH SarabunPSK

3. เริ่มต้นครั้งแรก

ครั้งแรกที่เปิดจะมีหน้าต่างต้อนรับ 3 ปุ่ม:

ปุ่มใช้เมื่อ
ทดลองด้วยข้อมูลตัวอย่างอยากลองระบบทันที — โหลดชุดคำถาม 6 วิชา กระดาน 3 แบบ และผลการแข่งขันตัวอย่าง (ชื่อสมมติ)
เริ่มใหม่ (ข้อมูลว่าง)เริ่มใช้จริง สร้างชุดคำถามของตัวเอง
เปิดไฟล์ข้อมูลเดิมมีไฟล์ .json ที่สำรองไว้จากเครื่องอื่น

ตั้งค่าข้อมูลโรงเรียน (ทำครั้งเดียว)

เมนู ตั้งค่าและข้อมูลโรงเรียน → กรอกชื่อโรงเรียน ส่วนราชการ ผู้รับรายงาน ผู้รายงานและตำแหน่ง (กดชิปข้อความสำเร็จรูปได้) ข้อมูลนี้ใช้ในทุกเอกสาร ช่องที่เว้นว่าง เอกสารจะเว้นจุดไข่ปลาให้เขียนเอง

ส่วน แม่แบบข้อความในเอกสาร แก้ถ้อยคำในใบสรุปผลและบันทึกข้อความได้ทุกช่อง คำในวงเล็บปีกกา เช่น {กิจกรรม} {จำนวนทีม} ระบบเติมให้อัตโนมัติ กด "ค่าเริ่มต้น" เพื่อคืนข้อความเดิม

4. ชุดคำถาม

เมนู ชุดคำถาม → สร้างชุดใหม่ (ใส่ชื่อชุด เลือกวิชา ระดับชั้น) แล้วเพิ่มคำถาม

เพิ่มคำถามทีละข้อ

  • กดปุ่มด้านล่าง ปรนัย / ถูก-ผิด / เติมคำ แล้วพิมพ์คำถาม (หรือกดชิปคำขึ้นต้นสำเร็จรูป เช่น "ข้อใดถูกต้อง")
  • ปรนัย: พิมพ์ตัวเลือก ก–ง แล้วกดวงกลมหน้าตัวเลือกที่ถูก
  • ถูก-ผิด: กดเลือกเฉลย ถูก หรือ ผิด
  • เติมคำ: พิมพ์เฉลย ถ้ามีหลายคำตอบที่ถือว่าถูกให้คั่นด้วย / เช่น 60/หกสิบ ระบบตรวจโดยไม่สนช่องว่างและตัวพิมพ์เล็ก-ใหญ่ รองรับเลขไทย
  • รูปประกอบ: กดกล่อง "เพิ่มรูป" เลือกไฟล์รูป ระบบย่อรูปให้อัตโนมัติ (เก็บในไฟล์สำรองด้วย)
  • ช่อง "คำอธิบายเฉลย" (ไม่บังคับ) จะแสดงหลังทีมตอบ
  • ทุกช่องบันทึกอัตโนมัติ ปุ่มลูกศรเลื่อนลำดับ ปุ่มสำเนา และปุ่มลบ (มีถามยืนยัน)

นำเข้าจาก Excel

  1. หน้า ชุดคำถาม กด แม่แบบ Excel จะได้ไฟล์ แม่แบบคำถาม_เกมบันไดงู.xlsx
  2. กรอกคอลัมน์: ประเภท | คำถาม | ตัวเลือก ก | ข | ค | ง | เฉลย | คำอธิบาย (ประเภทพิมพ์ ปรนัย / ถูกผิด / เติมคำ — เว้นว่างได้ ระบบเดาให้)
  3. กด นำเข้าจาก Excel เลือกไฟล์ → ระบบสร้างชุดใหม่ แถวที่กรอกผิดจะถูกข้ามพร้อมบอกเลขแถว
  4. หรือในหน้าแก้ไขชุด: คัดลอกแถวจาก Excel มาวางในช่อง "เพิ่มหลายข้อพร้อมกัน" แล้วกด เพิ่มจากที่วาง (แบบย่อ 2 คอลัมน์ คำถาม | คำตอบ ก็ได้)
ปุ่ม ส่งออกชุดคำถามเป็นไฟล์ .json ส่งให้ครูท่านอื่นกด "นำเข้าชุด (.json)" ได้ • ปุ่ม "ส่งออกชุดนี้เป็น Excel" ใช้แก้ไขต่อใน Excel

5. ออกแบบกระดานบันไดงู

เมนู ออกแบบกระดาน → สร้างกระดานใหม่ เลือกจำนวนช่อง 30 / 36 / 40 / 48 / 50 / 60 / 64 / 70 / 80 / 90 / 100 ระบบวางบันได งู ช่องคำถาม และช่องพิเศษให้อัตโนมัติ

เครื่องมือวิธีใช้
ช่องคำถาม / โบนัส / หยุดพัก / ทอยอีกเลือกเครื่องมือ แล้วคลิกช่องบนกระดาน
ช่องธรรมดาคลิกช่องเพื่อล้างชนิดช่อง
วางบันไดคลิกช่องเชิงบันได (ล่าง) แล้วคลิกช่องปลายบันได (บน)
วางงูคลิกช่องหัวงู (บน) แล้วคลิกช่องหางงู (ล่าง)
เอาบันได/งูออกคลิกช่องเชิงบันไดหรือหัวงู หรือกด × ในรายการด้านขวา
สุ่มวางอัตโนมัติกำหนดจำนวนบันได งู ร้อยละช่องคำถาม ช่องพิเศษ แล้วกด "สุ่มใหม่"
แนะนำ: เวลา 1 คาบ (50 นาที) 4 ทีม ใช้กระดาน 50 ช่อง • ป.ต้น หรือเวลาน้อยใช้ 30 ช่อง • กิจกรรมใหญ่ใช้ 100 ช่อง • การออกแบบบนคอมหรือแท็บเล็ตสะดวกกว่ามือถือ

6. เล่นเกมหน้าชั้นเรียน

ตั้งค่าเกม

  1. เมนู เล่นเกมบันไดงู เลือก ชุดคำถาม และ กระดาน (หรือ "สุ่มกระดานใหม่")
  2. เลือกจำนวนทีม 2–6 ทีม และชื่อทีมสำเร็จรูป (สี / สัตว์ / กลุ่ม / คณะสี) แก้ชื่อได้
  3. เลือกกติกา: เวลาตอบต่อข้อ (15–60 วินาที หรือไม่จับเวลา) ตอบถูกเดินต่อกี่ช่อง ตอบผิดถอยกี่ช่อง และ "ต้องทอยพอดีเส้นชัย"
  4. ใส่ข้อมูลกิจกรรม (ชื่อกิจกรรม วันที่ สถานที่ กรรมการ) สำหรับเอกสาร แล้วกด เริ่มเกม

ระหว่างเล่น

  • กด ทอยลูกเต๋า หรือแป้น Space ลูกเต๋าหมุนแล้วหมากเดินทีละช่อง ด้านขวาแสดงตาของทีม ตำแหน่ง จำนวนตอบถูก/ผิด และประวัติคำถามล่าสุด
  • หยุดที่เชิงบันได → ปีนขึ้น • หยุดที่หัวงู → ไถลลง • ช่องโบนัสเดินหน้าเพิ่ม • ช่องหยุดพักข้ามตาครั้งหน้า • ช่องทอยอีกครั้ง
  • หยุดที่ช่อง → หน้าต่างคำถามขึ้นพร้อมจับเวลา
  • ปรนัย/ถูก-ผิด: คลิกคำตอบที่ทีมเลือก (หรือกดแป้น 1–4) ระบบตัดสินและแสดงเฉลยทันที
  • เติมคำ: พิมพ์คำตอบของทีมแล้วกด "ส่งคำตอบ" ระบบตรวจให้ หรือครูกด "ตอบถูก/ตอบผิด" เอง และเปลี่ยนผลภายหลังได้ (นับว่าถูก/นับว่าผิด)
  • หมดเวลา = ตอบผิด • กด เดินต่อ / ถอยหลัง (หรือ Enter) หมากจะเดินตามผล • ปุ่ม "ข้ามคำถาม" = อยู่ช่องเดิม
  • ปิดเบราว์เซอร์กลางเกมได้ เปิดใหม่เกมยังค้างอยู่ เล่นต่อได้ทันที

ผู้ชนะ

ทีมแรกที่ถึงช่องสุดท้ายชนะ ระบบประกาศผลพร้อมพลุ เสียงแตร และแท่นรางวัล 3 อันดับ (อันดับถัดไปเรียงตามช่องที่ถึง) ถ้าหมดเวลาคาบ กด จบเกม ระบบจัดอันดับตามตำแหน่งปัจจุบัน

แป้นลัดการทำงาน
Space / Enterทอยลูกเต๋า / ไปต่อหลังตอบคำถาม
1–4เลือกคำตอบ ก–ง (ถูก-ผิด: 1 = ถูก, 2 = ผิด)
F / Mเต็มจอ / เปิด-ปิดเสียง

7. ผลการแข่งขัน ประวัติคำถาม และรายงาน

เมนู ผลและประวัติคำถาม → เลือกเกม จะเห็นอันดับ ตำแหน่งสุดท้ายบนกระดาน และประวัติคำถามรายข้อ (ทีม คำตอบของทีม เฉลย ผล เวลาที่ใช้ ช่องก่อน-หลัง)

ปุ่มได้อะไร
พิมพ์ใบสรุปผลใบสรุปผล A4 (อันดับ + ประวัติคำถาม + ช่องลงนามกรรมการ) พิมพ์หรือบันทึกเป็น PDF
สรุปผล (.docx)สรุปผลการแข่งขัน + ประวัติคำถาม ตามรูปแบบงานสารบรรณ (TH SarabunPSK 16 pt)
บันทึกข้อความ (.docx)บันทึกข้อความรายงานผลการจัดกิจกรรม พร้อมสรุปผลแนบท้าย — กรอกเลขที่หนังสือ/วันที่/ผู้รายงานในหน้าต่างก่อนดาวน์โหลด
ชุดคำถามพร้อมเฉลย (.docx)อยู่ในหน้าแก้ไขชุดคำถาม และหน้าพิมพ์
ถ้อยคำในเอกสารเป็นตัวอย่างที่โรงเรียนทั่วไปใช้ ตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ — ควรให้ฝ่ายวิชาการ/งานสารบรรณของโรงเรียนตรวจเทียบแบบฟอร์มที่ใช้อยู่จริง แล้วแก้ที่ "ตั้งค่า → แม่แบบข้อความในเอกสาร" ระบบไม่เดาเลขที่หนังสือหรือชื่อที่ไม่มีในข้อมูล (เว้นจุดไข่ปลาให้)

8. พิมพ์เล่นแบบกระดาษ

เมนู พิมพ์กระดาน + การ์ดคำถาม เลือกสิ่งที่จะพิมพ์ ดูตัวอย่างบนจอ แล้วกด พิมพ์ / บันทึก PDF

  • กระดาน — A4 แนวนอน พร้อมวิธีเล่นและความหมายของช่อง (พิมพ์สี แนะนำขยาย A3 ด้วยเครื่องถ่ายเอกสาร)
  • การ์ดคำถาม — A4 หน้าละ 8 ใบ ตัดตามเส้นประ เฉลยพิมพ์กลับหัวด้านล่าง พับซ่อนได้
  • ใบเฉลย — ตารางคำถามและเฉลยทั้งชุดสำหรับครู

9. สำรองข้อมูลและย้ายเครื่อง

  • ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ หากล้างประวัติเบราว์เซอร์ ข้อมูลจะหาย — กดปุ่ม บันทึกไฟล์ข้อมูล (.json) (มุมขวาบน) เป็นประจำ เก็บไฟล์ในแฟลชไดรฟ์หรือ Google Drive
  • เมื่อมีข้อมูลที่ยังไม่สำรอง กล่องมุมซ้ายล่างจะขึ้นสีเตือน
  • ย้ายเครื่อง: คัดลอกโฟลเดอร์ระบบ + ไฟล์ .json ไปเครื่องใหม่ เปิด index.html → เมนู สำรอง / เปิดไฟล์ข้อมูล → เปิดไฟล์ข้อมูล (.json)
  • เปิดไฟล์ผิดหรือพลาด กด กู้คืนข้อมูลชุดก่อนหน้า ได้ 1 ครั้ง
  • ล้างข้อมูลทั้งหมด มีหน้าต่างยืนยันก่อนเสมอ

10. คำถามพบบ่อย

ไม่มีเสียง? เบราว์เซอร์จะเล่นเสียงได้หลังคลิกหน้าจอ 1 ครั้ง ตรวจปุ่มลำโพงบนกระดานและความดังที่หน้า "ตั้งค่า" ต้องต่ออินเทอร์เน็ตไหม? ไม่ต้อง ทุกอย่างอยู่ในโฟลเดอร์ระบบ ใช้ในห้องเรียนที่ไม่มีเน็ตได้ ใช้บนมือถือ/แท็บเล็ตได้ไหม? ได้ทุกหน้า หน้าจอปรับตามขนาด แต่การออกแบบกระดานและพิมพ์เอกสารบนคอมสะดวกกว่า คำถามหมดชุดแล้วเป็นอย่างไร? ระบบสุ่มลำดับคำถามใหม่ทุกเกม ถ้าถามครบทุกข้อแล้วจะวนกลับไปข้อแรก แนะนำชุดละ 15–30 ข้อสำหรับกระดาน 50–100 ช่อง ตอบถูกแล้วไปตกช่องคำถามอีก? ไม่ถามซ้อน เพื่อไม่ให้เกมยืดเยื้อ แต่ถ้าไปตกเชิงบันไดหรือหัวงูจะมีผลตามปกติ เกมค้างเมื่อปิดเบราว์เซอร์? เปิดใหม่ เมนู "เล่นเกมบันไดงู" จะกลับไปเกมที่ค้างให้อัตโนมัติ ไฟล์ .docx ตัวอักษรเพี้ยน? ติดตั้งฟอนต์ TH SarabunPSK แล้วเปิดใหม่ใน Microsoft Word Excel นำเข้าไม่ได้บางแถว? ระบบแจ้งเลขแถวและสาเหตุ เช่น เฉลยปรนัยต้องพิมพ์ ก ข ค ง ตรงกับตัวเลือกที่มีข้อความ
