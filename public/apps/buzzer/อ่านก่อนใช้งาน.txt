ระบบกดปุ่มตอบเร็ว (Buzzer) แข่งตอบคำถามหน้าชั้นเรียน v1.0 — System ห้องสื่อครูคอม

วิธีเริ่มใช้งาน
1. แตกไฟล์ zip นี้ไว้ในเครื่อง (อย่าเปิดจากใน zip โดยตรง)
2. ดับเบิลคลิก index.html (เปิดด้วย Google Chrome หรือ Microsoft Edge)
3. ไม่ต้องติดตั้งโปรแกรม ไม่ต้องต่ออินเทอร์เน็ต
4. ครั้งแรกเลือก "ทดลองด้วยข้อมูลตัวอย่าง" หรือ "เริ่มใหม่ (ข้อมูลว่าง)"

ปุ่มลัดในหน้าแข่งขัน
Space = เปิดรับการกด · Enter = ถูก · X = ผิด · R = เฉลย · N = ข้อถัดไป · B = กระดานคะแนน · F = เต็มจอ

สำคัญ
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ กรุณากด "บันทึกไฟล์ข้อมูล (.json)" สำรองไว้เสมอ
- ข้อความอ้างอิงระเบียบในเอกสารเป็นค่าเริ่มต้น ควรให้เจ้าหน้าที่การเงิน/พัสดุตรวจก่อนใช้จริง (แก้ได้ที่ ตั้งค่าและแม่แบบ)
- รายละเอียดทั้งหมดอยู่ใน "คู่มือการใช้งาน.pdf" ในโฟลเดอร์ docs
