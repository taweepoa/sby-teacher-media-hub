## ระบบสื่อการสอนและเกมการศึกษาเชิงรุก (7 ระบบ)

1. 🎡 **วงล้อสุ่มรายชื่อนักเรียน (`vs-random-picker`)** — สุ่มรายชื่อ, สุ่มจับกลุ่มคละเพศ, สุ่มลำดับนำเสนอ, สุ่มตัวเลข, จับฉลากของรางวัล และสุ่มผังที่นั่ง
2. ⭐ **กระดานแต้มพฤติกรรมห้องเรียน (`vs-class-points`)** — สะสมแต้มความดีรายคนและรายกลุ่ม แลกของรางวัล และสรุปสถิติพฤติกรรม
3. 💰 **เกมเศรษฐีตอบคำถามหน้าชั้นเรียน (`vs-millionaire-quiz`)** — แข่งขันตอบคำถามไต่ระดับ 15 ขั้น พร้อมตัวช่วย 3 รูปแบบ และระบบออกเกียรติบัตร
4. 🃏 **เกมจับคู่ความจำและเกมทายใจ (`vs-memory-game`)** — เปิดไพ่จับคู่, ลากเส้นจับคู่, ทายใจ และกล่องสุ่มรางวัล
5. 🐍 **เกมบันไดงูตอบคำถามหน้าชั้นเรียน (`vs-snake-ladder-quiz`)** — เกมกระดานบันไดงูทบทวนบทเรียน รองรับหลายทีมพร้อมกัน
6. 🚨 **ระบบกดปุ่มตอบเร็ว Buzzer (`vs-buzzer`)** — แข่งขันกดปุ่มชิงสิทธิ์ตอบคำถามหน้าชั้นเรียน รองรับ 2–8 ทีม
7. ⏱️ **นาฬิกาจับเวลาหน้าชั้นเรียน (`vs-classroom-timer`)** — นาฬิกาจับเวลาขนาดใหญ่สำหรับโปรเจกเตอร์ จับเวลาหลายช่วง ตารางออดคาบเรียน และไฟจราจรวัดเสียงดัง

## การเชื่อมต่อ GitHub กับ Cloudflare Pages & D1

### 1. ตั้งค่า Cloudflare Pages จาก GitHub Repository นี้
1. เข้าสู่ **Cloudflare Dashboard** → **Workers & Pages** → **Create** → แท็บ **Pages** → **Connect to Git**
2. เลือก Repository **`taweepoa/sby-teacher-media-hub`**
3. ตั้งค่า Build Settings:
   * **Production branch:** `main`
   * **Build command:** *(เว้นว่างไว้)*
   * **Build output directory:** `public`
4. กด **Save and Deploy**

### 2. สร้างและผูกฐานข้อมูล Cloudflare D1
สามารถสร้างผ่านหน้าเว็บ Cloudflare Dashboard หรือรันผ่าน CLI:
```bash
# สร้างฐานข้อมูล D1
npx wrangler d1 create sby_media_hub_db

# รันคำสั่งสร้างตารางจากไฟล์ schema.sql
npx wrangler d1 execute sby_media_hub_db --remote --file=./schema.sql
```
จากนั้นในหน้าโปรเจกต์ Cloudflare Pages → **Settings** → **Bindings** → **Add** → **D1 database**:
* **Variable name:** `DB`
* **D1 database:** เลือก `sby_media_hub_db`
